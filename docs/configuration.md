# 配置参考

WeTypeX 的独立设置窗口配置文件路径：

```text
${XDG_CONFIG_HOME:-$HOME/.config}/ibus/wetypex/wetypex.json
```

## 输入

- 输入方式：全拼、七种双拼、三种五笔。搜狗、微软、紫光双拼组合内的 `;` 优先作为 `ing` 编码，空组合时仍按标点处理。
- 智能拼写：启用原版纠错候选。
- 表情和颜文字：控制原版 emoji、颜文字与符号候选。
- 微信表情：仅在能够识别的微信客户端中推荐，使用原版图片和 Linux 微信支持的文本别名；安装与 Wayland 应用识别范围见 [Linux 微信表情](wechat-emoticons.md)。
- 默认语言：默认使用中文，在设置界面中可选择首次启动时默认中文或英文；输入法窗口继承等均由 IBus 框架接管。
- 符号自动转换：中文半角输入中，数字间的冒号、逗号和句号在后一个数字输入时转为 ASCII，例如 `3。14` → `3.14`。普通中文句号保持原样；关闭该选项、使用全角或英文标点时沿用对应模式。
- 模糊拼音：原版 19 组模糊音可独立开关。
- 单机模式：禁止云候选和设备同步相关联网。

## 快捷键

快捷键使用 IBus 原生映射，可在系统配置页直接捕获。默认值包括：

| 操作 | 默认按键 |
| --- | --- |
| 中英文切换 | `Shift` |
| 候选翻页 | `Pgup` / `Pgdn` |

## 设备同步

三个同步开关会直接写入官方设备组功能位。没有完成配对时，独立设置窗口会禁用这些开关。切换失败时界面恢复服务器返回的原状态。

## 手工恢复

配置损坏时先退出 IBus，备份并移走 `wetypex.json`，再重新启动。插件会使用内置默认值创建新配置。不要为了重置界面删除 `account` 或 `state`，否则会丢失配对身份和用户词库。
