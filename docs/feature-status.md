# 功能状态

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 全拼 | 可用 | 原版候选、选词、部分选择和用户词频 |
| 双拼 | 可用 | 自然码、搜狗、微软、小鹤、拼音加加、紫光、智能 ABC |
| 五笔 | 可用 | 86、98、新世纪方案 |
| 智能拼写 | 可用 | 提供原版纠错能力 |
| 表情与颜文字 | 可用 | 普通 emoji 与颜文字保持原样；微信专属表情仅在可识别的微信客户端推荐，原图从用户提供的安装包生成本地彩色字体 |
| 模糊拼音 | 可用 | 原版 19 组声母、韵母和易混读音开关 |
| 云候选 | 可用 | 仅在联网且非单机模式启用；云端新增候选带 ☁ 标记，结果变化主动推送到前端 |
| 简繁、标点、全半角 | 预览 | 支持自动符号转换，符号补全不支持，全半角快捷键暂未迁移 |
| 常用语 | 可用 | 设置窗口支持添加、编辑和删除，并直接写入原版核心 |
| 官方设备配对 | 可用 | 真实六位码、状态轮询与确认绑定 |
| 文字剪贴板同步 | 可用 | 与关联设备双向同步 |
| 图片同步 | 可用 | 与关联设备双向同步 |
| 个人词库同步 | 预览 | 原版同步器已接入，复杂冲突合并仍有限制 |
| 常用语同步 | 预览 | 原版同步器已接入，复杂冲突合并仍有限制 |
| 剪贴板历史记录 | 不提供 | 不在 IBus 首版范围内 |
| 语音输入 | 不提供 | 不在 IBus 首版范围内 |
| 语音标点与智能整理 | 不提供 | 不在 IBus 首版范围内 |
| 问 AI | 不提供 | 不在 IBus 首版范围内 |
| 隔空传送 | 不提供 | 不在 IBus 首版范围内 |
| V 模式 | 不提供 | 不在 IBus 首版范围内 |
| 桌面悬浮工具栏 | 不提供 | 不在 IBus 首版范围内 |
| 检查更新 | 可用 | 在设置的关于页面手动检查；安装时下载并校验适用于当前发行版的软件包，通过 pkexec 提权安装 |
