# 按键与输入模式

以下规则适用于已启用且有焦点的 WeTypeX 输入上下文。密码和 PIN 输入框不会启用输入核心。系统或应用提前处理的按键不会到达输入法。

## 输入模式与中英文切换

设置中的输入方案包括全拼、双拼和五笔；双拼和五笔方案可在设置中选择。中文模式下，字母按当前方案送入原版输入核心。拼音组合内的单引号（`'`）用作音节分隔符；五笔组合内的单引号不作分隔符，而按标点处理。

单独短按并松开 Shift 可切换中英文，默认启用；Ctrl 切换默认关闭，可在“快捷键”设置页启用。Shift+字母仍可输入大写编码；Ctrl、Alt、Super、Meta、Hyper 等修饰键组合交给应用。也可点击 IBus 属性面板中的“中文”或“英文”切换。

## 输入状态切换

“快捷键”设置页可启用以下状态切换：

| 按键 | 作用 |
| --- | --- |
| Shift+Space | 切换全角/半角。中英文模式均生效；英文模式下可打印 ASCII 字符转为全角，中文模式下直接输入的空格、数字及英文标点按全角状态输出。拼音、五笔编码不转换 |
| Ctrl+. | 仅在中文模式下切换中文/英文标点；该快捷键默认关闭 |
| Ctrl+Shift+F | 仅在中文模式下切换简体/繁体，并重建后端会话；该快捷键默认关闭 |

全角状态、标点状态和简繁状态会保存到用户配置。关闭中文标点后，英文标点按全角状态输出 ASCII 或全角形式。

## 组合编辑与候选

| 按键 | 有中文组合时 | 没有组合时 |
| --- | --- | --- |
| Space | 选择高亮候选 | 交给应用 |
| `1` 至每页候选数（默认 `1`–`5`） | 选择当前页对应候选 | 交给应用 |
| `0` | 不作为候选序号，交给应用 | 交给应用 |
| Enter | 提交原始组合文本 | 交给应用 |
| Esc | 取消当前组合 | 交给应用 |
| Backspace、Delete | 删除光标前或后的组合字符 | 交给应用 |
| Left、Right、Home、End | 移动组合光标 | 交给应用 |
| Up、Down | 移动候选高亮 | 交给应用 |
| PageUp、PageDown | 翻候选页 | 交给应用 |
| `-` / `=` | 上一页 / 下一页（需启用对应快捷键） | 交给应用 |
| `[` / `]` | 上一页 / 下一页（需启用对应快捷键） | 交给应用 |
| `,` / `.` | 上一页 / 下一页（需启用对应快捷键） | 交给应用 |
| Shift+Tab / Tab | 上一页 / 下一页（需启用对应快捷键） | 交给应用 |

数字小键盘 `1` 至 `9` 可选词，但默认关闭，可在“快捷键”设置页启用；小键盘 `0` 不选词。主键盘数字键和空格选词始终可用。每页候选数可在设置中调整为 3 至 9。候选尚未返回时，输入法会等待候选结果再处理选词。

## 标点

中文模式下，“中文标点”开关决定使用中文还是英文标点；不再根据光标前的字符自动判断。启用 Ctrl+. 快捷键后，可在中文模式下临时切换此状态。“将「/?」替换为 、”选项开启时，使用中文标点时 `/` 输出 `、`。关闭中文标点后，英文标点根据全角状态输出半角或全角形式。

IBus 前端无法在所有应用中将光标放到成对符号中间，因此输入左括号、书名号、方括号或花括号时只提交左侧符号，不会自动补右侧符号，也不支持自动跳过已有右括号。中文组合中输入标点会先结束当前组合，再提交标点。

英文模式下不执行中文标点转换；全角状态开启时，可打印 ASCII 输入会转换为全角字符。
