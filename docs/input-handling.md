# 按键与输入模式

以下规则适用于已启用且有焦点的 WeTypeX 输入上下文。密码和 PIN 输入框不会启用输入核心。系统或应用提前处理的按键不会到达输入法。

## 输入模式与中英文切换

设置中的输入方案包括全拼、双拼和五笔；双拼和五笔方案可在设置中选择。中文模式下，字母按当前方案送入原版输入核心。拼音组合内的单引号（`'`）用作音节分隔符；五笔组合内的单引号不作分隔符，而按标点处理。

单独按下并松开 Shift 可切换中英文（需启用“使用 Shift 切换中英文”）。Shift+字母仍可输入大写编码；Ctrl、Alt、Super、Meta、Hyper 等修饰键组合交给应用。也可点击 IBus 属性面板中的“中文”或“英文”切换。

## 组合编辑与候选

| 按键 | 有中文组合时 | 没有组合时 |
| --- | --- | --- |
| Space | 选择高亮候选 | 交给应用 |
| `1` 至每页候选数（默认 `1`–`5`） | 选择当前页对应候选 | 交给应用 |
| `0` | 不作为候选序号，交给应用 | 交给应用 |
| Enter | 提交原始组合文本 | 交给应用 |
| Esc | 取消当前组合 | 交给应用 |
| Backspace、Delete | 删除光标前或后的组合字符 | 交给应用 |
| Left、Right、Home、End | 移动组合光标 | 交给应用 |
| Up、Down | 移动候选高亮 | 交给应用 |
| PageUp、PageDown | 翻候选页 | 交给应用 |

数字小键盘 `1` 至 `9` 也可选词；`0` 不选词。每页候选数可在设置中调整为 3 至 9。候选尚未返回时，输入法会等待候选结果再处理选词。

## 标点

中文模式下，输入法按“中文标点”设置转换标点；关闭该选项时使用英文标点。“将「/?」替换为 、”开启时，中文标点模式下 `/` 输出 `、`。单引号作为标点处理时，以及双引号输入时，会在弯引号的左右形式间交替。

IBus 前端无法在所有应用中将光标放到成对符号中间，因此输入左括号、书名号、方括号或花括号时只提交左侧符号，不会自动补右侧符号，也不支持自动跳过已有右括号。中文组合中输入标点会先结束当前组合，再提交标点。

英文模式下，按键直接交给应用，不执行中文标点转换。IBus 版本不提供自定义候选/翻页快捷键、V 模式或 AI 按键入口；不要套用其他前端版本的按键说明。
